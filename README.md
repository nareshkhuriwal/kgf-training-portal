# KGF Online Training – React UI (Udemy-like Home)

**Stack**: React 18, Vite 5, Redux Toolkit, React Router v6, TailwindCSS.

## Quick start

```bash
npm i
npm run dev
# build
npm run build && npm run preview
```

## Structure

- `src/pages` – Home, Catalog, Course
- `src/components` – Layout, Header, Footer, Hero, Carousel, Card
- `src/store` – Redux Toolkit slices (`ui`, `user`, `courses`)
- `src/services` – axios instance
- `src/data/catalog.json` – mock data (replace with API)
